HOW TO READ THE EVIDENCE

  • HRV: use validated RR/IBI data, artifact cleaning, a standardized baseline, and matched low-motion windows. Lower vagally mediated HRV can accompany acute stress, but also changes with movement, breathing, posture, temperature, and excitement.
  • Outcomes: distinguish momentary experience, post-event evaluation, intention, and actual repeat behavior.
  • Inference: test time-aligned associations; do not imply causality unless the design supports it.

COMPANION METHODS

Pair HRV + EMA at the same moment. Add interviews for meaning and social media data for broader post-event discourse. This multimodal logic has been used to study daily stress in naturalistic settings (Yao et al., 2024; Jordan et al., 2023; Greenwell et al., 2025).
